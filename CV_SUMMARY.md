# Full Stack Developer CV Summary - HairStudio 89

## 🎯 Project Overview
**Sole Developer & Designer** — Luxury Hair Salon Marketing Website  
**Duration**: Full project lifecycle from concept to deployment  
**Status**: Live production website hosted on Vercel  
**Client**: HairStudio 89 — a premium, genderless hair salon in Pimlico, London, specialising in lived-in colour, balayage, and bespoke styling by Araceli Perez and Daniel Matez

---

## 🚀 **Full Stack Development Achievements**

### **Frontend Development**
• **React 19 & Next.js 16**: Built a performant single-page marketing site with the App Router  
• **TypeScript 5**: Type-safe components, API responses, and shared configuration across the app  
• **Responsive Design**: Mobile-first layout with adaptive gallery grids, horizontal scroll strips, and a collapsible navigation menu  
• **Component Architecture**: Modular sections (Hero, Services, Team, Testimonials, Gallery, Contact) with clear separation of concerns  
• **Hero Video Experience**: Custom dual-layer video player with seamless crossfade looping for a cinematic landing experience  
• **Luxury UI/UX**: Serif/sans typography pairing (Fraunces & Inter), refined spacing, and subtle hover micro-interactions throughout  

### **Backend & API Development**
• **Instagram Feed Integration**: Custom API route proxying FeedFramer with hourly ISR caching and graceful degradation  
• **Curated Fallback Gallery**: Static gallery data when the live feed is unconfigured or unavailable, ensuring the site always looks complete  
• **Environment-Based Configuration**: Secure API key handling for third-party services via environment variables  
• **External Booking Integration**: Salon IQ booking portal linked site-wide for appointment reservations  

### **Content & Business Features**
• **Services Showcase**: Signature offerings (Luxury Blowout, Balayage & Gloss, Treatment Ritual) with enquiry CTAs  
• **Team Profiles**: Stylists presented with bespoke monogram cards and professional bios  
• **Client Testimonials**: Google review highlights to build trust and social proof  
• **Contact & Location**: Full salon details — address, opening hours, phone, email, and promotional offers  
• **Brand Partnership**: O&M product line featured with editorial-style presentation

## 📱 **User Experience & Design Skills**

### **Design Implementation**
• **Visual Identity**: Premium salon aesthetic aligned with the brand’s lived-in colour positioning

### **Performance & Optimisation**
• **ISR Caching**: Instagram feed revalidated every hour to balance freshness and performance  
• **Video Optimisation**: Muted, inline autoplay with preload for fast hero rendering  
• **SEO Optimisation**: Targeted metadata — “Luxury Hair Salon in Pimlico, London” with service-focused description  
• **Graceful Degradation**: Gallery, API, and booking flows remain functional when external services are unavailable

## 🔧 **Infrastructure & Deployment**

### **Hosting & Deployment**
• **Vercel Platform**: Production deployment with automatic builds and global CDN  
• **Environment Management**: Secure configuration for FeedFramer API keys  
• **Static Assets**: Self-hosted hero video and curated gallery imagery  

### **Security & Best Practices**
• **Environment Variables**: API keys kept server-side, never exposed to the client  
• **External Links**: `rel="noopener noreferrer"` on all third-party targets  
• **Error Handling**: Try/catch around upstream API calls with safe empty-state responses
